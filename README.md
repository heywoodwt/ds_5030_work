# Statistical Learning (UVA DS 5030)

Coursework for UVA's graduate statistical learning course, worked in Python.

| Notebook | Topic |
|----------|-------|
| `assignment_1-1.ipynb` | Data wrangling and exploratory analysis across several datasets |
| `assignment_2-2.ipynb` | Regression and model fitting |
| `assignment_3.ipynb` | Classification |
| `assignment_5.ipynb` | Resampling and model selection |
| `assignment_6.ipynb` | Regularization and tree-based methods |
| `assignment_7.ipynb` | Unsupervised methods |
| `dice_trials.ipynb` | Monte Carlo simulation exercise |
| `taxi_cab.ipynb` | Applied analysis on trip data |

Datasets under `data/` cover NHANES survey data, Ames housing prices, college
completion rates, breast cancer outcomes (METABRIC), Minneapolis police use-of-force
records, Virginia procurement records, and a small corpus of public-domain novels for
text work. `get_data.py` pulls the archive from Zenodo.

Built with `pandas`, `numpy`, `scikit-learn`, `matplotlib`, and `seaborn`.
